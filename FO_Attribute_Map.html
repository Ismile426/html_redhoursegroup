F&O → Pimcore — attribute mapping sheet

Generated from the live Pimcore classes on 23 Sep 2026. Do not hand-edit — re-run app:export-attribute-map.

Everything below already exists in Pimcore. These are all the places an attribute value can land. No PIM work is needed to add them.
The two yellow columns are what blocks POST /attributes. We cannot write a value until we know which F&O attribute name maps to which row, and what a real value looks like. Fill the rows F&O actually holds and leave the rest blank — blank means "F&O does not have this".

Three things to watch:

  1. Units. Rows typed quantityValue need the number and the unit as separate values. Do not send "35.00 mm" as one string.
  2. Metric vs imperial. Length and diameter exist twice, once per system. Tell us how to know which system an item uses.
  3. Code or label. Rows typed relation or select match on a code. If F&O sends a display word instead, say so in the example column.
